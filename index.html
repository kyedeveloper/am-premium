// Bot Telegram (node-telegram-bot-api)
import TelegramBot from 'node-telegram-bot-api';
import fetch from 'node-fetch';

const bot = new TelegramBot('BOT_TOKEN_KAMU', { polling: true });

bot.onText(/\/cek (.+)/, async (msg, match) => {
  const chatId = msg.chat.id;
  const apiKey = match[1].trim();

  try {
    const res = await fetch('https://www.juikoprem.my.id/api/auth/me', {
      headers: { 'X-Api-Key': apiKey, 'Content-Type': 'application/json' }
    });
    const data = await res.json();
    if(!res.ok || !data.user) return bot.sendMessage(chatId, `❌ Key Tidak Valid`);

    bot.sendMessage(chatId, `✅ Email: \${data.user.email}\nSisa Kuota: \${data.quota?.remaining || 'Unlimited'}`);
  } catch(err) {
    bot.sendMessage(chatId, `⚠️ Server Error`);
  }
});

Pertanyaan

Hal yang sering ditanya

Metodenya meniru alur verifikasi pembelian dari aplikasi resmi, jadi akun akan terbaca premium di Alight Motion. Risikonya cuma satu: kalau server Google atau Alight mengubah skema, endpoint bisa berhenti sampai diperbaiki.

Biar server nggak kebanjiran dan biaya token tetap wajar. Akun free dapat 20 inject per hari, reset jam 00:00 WIB. Kalau butuh lebih, premium Rp3.500 sebulan tanpa batas.

Ya, begitu QRIS discan dan dibayar, status akun berubah otomatis dalam beberapa detik. Halaman pembayaran ngecek status sendiri, jadi nggak perlu kirim bukti transfer.

Cek folder spam/promosi dulu, tunggu 1–2 menit, lalu minta kode baru. Kode berlaku 10 menit dan cuma bisa dipakai sekali. Kalau email kantor kamu memblokir pengirim pihak ketiga, pakai jalur password.

Bisa. Parser akan mendekode URL, membuka parameter bersarang, dan mengambil nilai oobCode saja. Validator di kolom input langsung memberi tahu hasilnya sebelum kamu menembak API.

Email akun kamu disimpan di database untuk keperluan login dan hitung kuota. Riwayat aktivasi tetap di localStorage browser kamu sendiri dan bisa dihapus kapan saja lewat panel riwayat.

Itu tujuan fitur antrian dan order ID urut. Pakai mode Urut supaya ID transaksi berjalan konsisten, dan ekspor riwayat sebagai CSV untuk pembukuan.

Kenapa dibuat

AM Premium lahir dari satu masalah sederhana: proses aktivasi premium di aplikasi resmi itu panjang dan gampang salah. Kirim link, buka email, salin URL panjang, tempel ke tempat yang benar, baru jalankan.

Terminal ini memotong semua itu jadi dua kolom input dan satu tombol. Semua logika berat — login OOB, pemanggilan verifyPurchase, dan penyimpanan token — dipindah ke serverless function supaya browser tetap bersih.

Prinsip desainnya: satu layar, dua langkah, nol token di frontend. Kalau satu langkah gagal, terminal bilang persis di mana masalahnya.
